# Мобильный органайзер домашних растений

Вариант 7. Заяц М.С., ИТИ-41.
Репозиторий: https://github.com/Jewilor/home-plants-organizer

## Адаптация общих и архитектурных требований

Dart и Flutter Material вместо Swift и SwiftUI. Основная платформа — Android, демонстрация на устройстве или эмуляторе Android Studio. MVVM сохраняется: Model — данные и правила предметной области; ViewModel на ChangeNotifier — состояние и действия; View — декларативные виджеты, подписанные на изменения. Исходный документ допускает Flutter по согласованию с преподавателем. Адаптация выполнена по запросу студента; факт согласования с преподавателем не утверждается.

## Последовательность работ

| Работа | Цвет | Содержание |
| --- | --- | --- |
| 1 | Зелёный | Список растений, интерактивный календарь процедур, цветовые индикаторы просроченного полива |
| 2 | Лиловый | Журнал ухода, ботаническая справка, OCR текстового названия с этикетки |
| 3 | Жёлтый | Реляционная БД растений, процедур, расписания; нереляционное хранилище семейств и удобрений |
| 4 | Голубой | REST-запрос по названию, сохранение регламента ухода, локальные уведомления |

Для следующих этапов: SwiftData → SQLite; Realm → отдельное нереляционное хранилище; Codable → Dart JSON; Combine → Streams и async/await; URLSession → HTTP-клиент; UserNotifications → локальные уведомления Android. Пакеты выбираются и проверяются при выполнении этапа. Сканер штрихкодов не заменяет OCR.

## Границы лабораторной 1

Демонстрационные данные в памяти. Нет постоянного хранения, камеры, REST и уведомлений: эти функции относятся к следующим работам. Просрочка вычисляется относительно текущей локальной календарной даты, независимо от выбранного дня календаря. Сегодняшний срок не просрочен.

Критерии: список растений и сроки полива; выбор дня и месяца; возврат к сегодня; процедуры выбранного дня и пустое состояние; красный фон просроченных карточек, янтарный для сегодняшнего срока, зелёный для будущего; текстовое дублирование статусов; работа на компактном экране.
