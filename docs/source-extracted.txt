Общие требования
Технические и архитектурные требования
Приложение должно быть реализовано на основе декларативного стэка Apple:
Язык программирования: Swift;
Интерфейс пользователя: SwiftUI;
Архитектурный паттерн: MVVM (Model-View-ViewModel).
В заданиях, где данные получаются через REST API, нет необходимости реализовывать собственный веб-сервис. Допускается создать mock-сервер в Postman (или другим аналогичным способом) или использовать любой открытый API-сервис, подходящий по тематике задания.
При отсутствии Mac-устройства для разработки, по согласованию с преподавателем, могут быть использованы следующие подходы:
Использование фреймворка Flutter и альтернативных технологий (BLoC, Cubit, Isar, Realm SDK, Streams, mobile_scanner, Dio, freezed, json_serializable);
Использование фреймворка React Native и альтернативных технологий (Zustand, WatermelonDB, @realm/react, RxJS, react-native-vision-camera, Axios, Zod);
Использование Mac Cloud;
Установка Hackintosh, как второй ОС, на Windows-устройство;
Запуск macOS в виртуальной машине под Windows;
Требования к отчету по лабораторным работам
Отчет должен обязательно включать следующую информацию:
Cсылку на открытый GitHub репозиторий;
Снимки экранов и функционала, описанного в задании;
Пример кода работы с хранилищами данных (БД, JSON-файлы, UserDefaults);
Пример кода описания пользовательского интерфейса;
Пример кода реализации шаблона MVVM;
Пример кода получения данных по сети (REST, Combine);
Примеркода реализации архитектурныхособенностей (если указанов индивидуальном задании).
Демонстрация готового приложения
При возможности, приложение должно быть запущено на реальном устройстве. При отсутствии реального устройства, допускается запуск в эмуляторе. В данном случае, для демонстрации работы с камерой, должен быть реализован программный mock с набором различных картинок штрихкодов.
