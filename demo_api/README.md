# Учебная энциклопедия

Эти данные используются для воспроизводимой демонстрации сетевого получения регламента ухода. Приложение загружает JSON через REST API содержимого открытого репозитория GitHub и выбирает точное совпадение названия или ботанического имени. Запрос содержит введённое название в параметре `q`; GitHub возвращает коллекцию, а сопоставление выполняется клиентом.

Это учебные данные, а интервалы полива заданы для проверки расписания. Они не выдаются за ответ Perenual. Для подключения Perenual применяется собственный ключ через `--dart-define=PERENUAL_API_KEY=...`; реализованы поиск вида и запрос его подробных данных. Ключ в репозиторий не добавляется.

Для использования другого учебного сервера задайте `--dart-define=PLANT_API_URL=https://адрес/путь`. Ответ должен содержать объект `data` с массивом записей того же формата. Необязательное поле `family` содержит название семейства: например, `Araceae`. Старые ответы без этого поля остаются совместимыми. При сохранении регламента существующее семейство выбирается по названию, а отсутствующее добавляется в справочник.


Семейства учебных растений проверены по ботаническим источникам: [монстера — Araceae](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A87478-1), [фикус — Moraceae](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A327905-2), [спатифиллум — Araceae](https://powo.science.kew.org/taxon/urn%3Alsid%3Aipni.org%3Anames%3A89011-1), [драцена — Asparagaceae](https://www.nparks.gov.sg/florafaunaweb/flora/2/4/2420), [аглаонема — Araceae](https://records.data.kew.org/occurrences/b863952b-c7c5-4861-91e7-b94b59ba77ac). Эти названия семейств не определяются по интервальным данным о поливе.
